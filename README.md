# Senga atalgan maktub

Sevgilingizga atalgan romantik, interaktiv maktub va biologiya viktorinasi. Oddiy HTML, CSS va JavaScript bilan qurilgan — framework yoki build jarayoni kerak emas.

## Imkoniyatlar

- Uch bosqichli romantik syurpriz va ochiladigan maktub.
- 6-, 7- va 8-sinf biologiyasidan tasodifiy viktorina savollari.
- Har bir to‘g‘ri javob uchun 10 coin; sovg‘ani ochish uchun 50 coin kerak.
- Coinlar brauzerning `localStorage` xotirasida saqlanadi.
- Telefon va kompyuter ekranlariga mos dizayn.

## Mahalliy ishga tushirish

`index.html` faylini brauzerda oching. Internetga ulangan bo‘lsangiz, Google Fonts shriftlari ham yuklanadi; shriftlar yuklanmasa, sahifa tizim shriftlaridan foydalanadi.

## Vercel’ga joylash

1. GitHub’dagi `quizpari` repositoriyasini Vercel’ga import qiling.
2. Framework Preset sifatida **Other** ni tanlang.
3. Root Directory qiymatini `.` holicha qoldiring.
4. Build Command va Output Directory uchun qiymat kiritish shart emas; Deploy tugmasini bosing.

Saytning bosh sahifasi `index.html` bo‘lib, qo‘shimcha server yoki environment variable talab qilmaydi.
